# 📘 Assignment: Testing Python Code with pytest

## 🎯 Objective

Practice writing automated tests for Python code using `pytest` so students can verify behavior, catch bugs, and build confidence in their programs.

- Focus on unit testing functions and handling edge cases.
- Learn how to use `pytest` assertions and exception checks.
- Practice organizing tests in a separate file.

## 📝 Tasks

### 🛠️ Review the provided functions

#### Description
Read the starter code and understand what each function does.

#### Requirements
Completed program should:

- Include functions for math and string behavior.
- Handle normal inputs and edge cases.
- Be ready to test each function with `pytest`.

### 🛠️ Write unit tests with pytest

#### Description
Create a test file that verifies the provided functions work as expected.

#### Requirements
Completed assignment should:

- Create a new file named `test_calculator.py`.
- Use `pytest` assertions to test each function.
- Include tests for valid input and expected output.
- Add a test that verifies `divide()` raises a `ZeroDivisionError` when dividing by zero.

### 🛠️ Add edge case coverage

#### Description
Write tests that check behavior for boundary values and unexpected input.

#### Requirements
Completed assignment should:

- Test `is_even()` with both even and odd numbers.
- Test `format_greeting()` with a sample name.
- Test `divide()` with a non-zero divisor.
- Use clear, readable assertions in the test file.
